상태: **시안 A — Club Lime 확정 · 2단계 코드 구현 완료, 커밋·브라우저 검증 보류**. 현재 환경의 `.git` 쓰기 제한과 Chrome 도구 승인 거부로 전체 완료는 아니다.

## 공통 적용 조건과 확인 사항

### 접근성과 반응형

- 대비율은 Python으로 sRGB를 선형화한 뒤 `L = 0.2126R + 0.7152G + 0.0722B`, `(L밝음 + 0.05) / (L어두움 + 0.05)`로 계산했다. `c ≤ 0.04045`이면 `c/12.92`, 나머지는 `((c+0.055)/1.055)^2.4`를 적용했다. 본문 4.5:1·큰 글씨 3:1 기준은 [WCAG 설명](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)을 따른다.
- 표는 불투명한 단색 조합의 계산값이다. 두 안 모두 `--text`, `--steel`, 강조·상태 텍스트와 세 배경의 조합이 4.5:1 이상이다. 실제 브라우저의 중첩 배경·hover·disabled·영상 위 표시까지 통과했다는 뜻은 아니며 구현 후 확인한다.
- `--graphite-3`의 연한 테두리는 장식용이다. 입력 경계처럼 식별이 필요한 곳에는 `--border-strong`을 사용한다. 두 안·두 테마 모두 세 배경과의 대비가 4.08:1 이상이다.
- 영상용 공통 추가 토큰은 `--media-bg: #080B0A`, `--media-text: #FFFFFF`, 모달 배경용은 `--overlay: rgb(0 0 0 / 64%)`이며 두 테마에서 같다. 영상 위 텍스트에는 불투명한 `--media-bg` 받침을 사용한다. 실제 카메라 영상·사진의 색은 테마 토큰의 대상이 아니다.
- `PHASE_COLORS`는 유지한다. 파형의 선과 테마용 fallback 색만 토큰에 연결하고, 상태 아이콘·라벨을 유지한다. `--warn` 적용은 표현 변경이며 `getStatus()` 판정은 변경하지 않는다.
- 1440px에서는 최대 너비 1160px, 390px에서는 가용 너비 350px를 기준으로 그리드·헤더를 줄바꿈한다. 긴 영문 페이즈명은 카드 안에서 줄바꿈하고, 가로 넘침을 페이지 전체의 `overflow-x: hidden`으로 감추지 않는다.
- A의 버튼 hover는 최대 2px 이동·160ms, B는 배경색·그림자 180ms 전환 정도로 제한한다. 자동 반복 장식은 추가하지 않으며 `prefers-reduced-motion: reduce`에서는 애니메이션과 전환을 `none`으로 끈다.

### 코드에서 확인한 기존 불일치

1. **스타일 연결:** `ResultScreen.module.css`의 `.num`, `.label`, `.k`, `.v`, `.tag`, `.txt`, `.cap` 등은 CSS Modules의 지역 클래스인데 JSX 일부는 같은 이름의 일반 문자열을 사용한다. 큰 점수·메트릭·진단 행 스타일을 적용할 때 `styles.*` 또는 명시적인 `:global(...)`로 연결을 맞추는 작업이 필요하다. 이는 R1이 허용하는 마크업·className·CSS 수정 범위다.
2. **샘플과 다시보기:** 수정된 완료 기준 7에 따라 샘플은 점수·메트릭·진단·파형·7단계 프레임·비교·코칭 패널을 확인한다. `SwingReplay`는 실제 업로드 때만 표시되는 정상 동작을 유지하며, 별도로 확인하지 못하면 미확인으로 기록한다.
3. **하드코딩 색:** Hero SVG, Waveform의 선, 영상 배경·오버레이 등에 기존 고정색이 있다. 선택된 안을 구현할 때 테마에 속하는 색은 토큰에 연결한다. R2가 고정한 페이즈색은 그대로 둔다.
4. **문서와 실제 테마:** UI 스킬의 소개에는 단일 다크 테마라고 적혀 있지만 실제 `index.css`와 `CLAUDE.md`에는 라이트 테마가 있다. 지시서와 실제 코드에 맞춰 두 테마를 모두 설계했다.
5. **산출물 경로:** 수정된 R1은 `docs/redesign-proposal.md`와 `docs/screenshots/*.jpg`를 허용한다. 완료 기준 3의 비교 기준은 리디자인 직전 커밋 `e973fb6`이다.
