## 3. 검증할 가설 — 각각 지지/기각/미확인 + 수치로 판정

## 5. 문헌·웹 조사 (실험 결과 해석용)
| RQ | 질문 |
|---|---|
| R1 | 골프 스윙 이벤트·단계 검출 방법: GolfDB/SwingNet(McNally 외 2019) 이후 영상 기반 방법, 포즈 시계열 기반 방법, 규칙 기반의 한계와 정확도 |
| R2 | **필요 프레임률**: 다운스윙·임팩트 시간 길이, 30/60/120/240fps에서 이벤트 검출 오차에 대한 보고 |
| R3 | 단안 2D 포즈 추정(MediaPipe 등)의 골프 적용 한계: 후방 촬영, 손·클럽 가림, 모션 블러, 작은 인물 |
| R4 | 프레임 보간(RIFE 등)·초해상도를 포즈/이벤트 검출 전처리로 쓴 연구 — 효과 있었는지, 빠른 동작에서 아티팩트 보고 |
| R5 | 무료로 쓸 수 있는 오픈소스(코드·사전학습 가중치·데이터셋): 이름, 저장소 URL, **라이선스(상업 이용 가능 여부)**, 요구 환경(GPU 등) |

출처 규칙(위반 항목은 무효):
1. 논문은 DOI 또는 공식 URL을 실제로 열어 **제목이 일치하는지** 확인한 것만(과거 DOI가 엉뚱한 논문으로 연결된 사례 있음). 확인 수준 `본문 확인`/`초록만 확인` 표시
2. 수치는 연 본문·초록에 있는 값만, 위치(표·그림·쪽)와 함께. 기억으로 쓰지 않는다
3. 오픈소스는 저장소의 LICENSE 파일을 열어 확인한 라이선스만. 없으면 "라이선스 없음(사용 불가 취급)"
4. 블로그·제품 페이지는 R5의 존재 확인 용도로만, 성능 근거로 쓰지 않는다
5. 모르는 것은 "미확인"
