## 1. 왜 조사하는가 (현재 문제 — 코드로 확인한 사실)
| 문제 | 코드 근거 |
|---|---|
| 스윙 단계를 **손목 y좌표 하나**로만 나눈다(어드레스 끝=손목 10% 상승, 톱=속도 부호 전환, 임팩트=톱 이후 손목 최저점). 골반·몸통 움직임은 단계 판정에 쓰지 않는다 | `golf_swing_analyzer/analyzer/phase_detector.py` |
| "골반/어깨 회전각"이 실제 축 회전이 아니라 **화면상 좌우 관절을 잇는 선의 기울기**(`arctan2(|dy|, |dx|)`)다 | `golf_swing_analyzer/analyzer/geometry.py` L44–54 |
| 회전 지표(X-Factor)가 음수(-17.5°)로 나오고 실행 환경마다 10~38° 흔들린다 | `docs/` 및 2026-10-08 실측(`RUNNING.md` 5절) |
| 입력은 **스마트폰 단안 2D 영상 + MediaPipe Pose(33 관절)** 이다 | `analyzer/mp_setup.py` |

목표: ① 단계를 더 세분화하고 ② **골반이 언제 움직이기 시작했는지**(다운스윙 개시·전환) 검출하며 ③ 스윙 인식률을 높이기 위한 **학술 근거**를 모은다. 이번 조사는 코드를 고치지 않는다.

## 2. 조사 질문 (RQ)
| RQ | 질문 |
|---|---|
| RQ1 | 운동학적 연쇄(kinematic sequence): 골반→흉곽(몸통)→팔→클럽의 각속도 피크 순서와 시간 간격은? 숙련도별 차이는? |
| RQ2 | 골반 움직임 개시·전환(transition): 다운스윙에서 골반이 언제 타깃 방향으로 회전/이동을 시작하는가(백스윙 톱 이전/이후)? 어떻게 측정·정의하는가? |
| RQ3 | 역학·에너지: 분절 간 에너지/각운동량 전달, 지면반력(GRF), X-Factor·X-Factor stretch와 클럽헤드 속도의 관계 |
| RQ4 | 스윙 단계 정의와 자동 이벤트 검출: 단계(어드레스·테이크어웨이·백스윙 중간·톱·전환·다운스윙 중간·임팩트·팔로우스루·피니시) 정의, 영상/IMU 기반 이벤트 검출 방법과 정확도 |
| RQ5 | 단안 2D 영상 포즈 추정으로 골프 측정: MediaPipe/OpenPose 등 vs 마커 모션캡처 정확도, **2D에서 축 회전(골반·흉곽) 추정 방법**(예: 어깨폭/골반폭 투영 비율, 깊이 추정), 촬영 방향(정면 face-on / 후방 down-the-line) 영향 |
| RQ6 | 인식률 평가용 공개 데이터셋·벤치마크(예: GolfDB)와 그 라이선스·평가 지표 |

## 3. 출처 기준 (위반 시 해당 항목 무효)
1. 학술 출처만: 동료심사 저널·학회 논문, 학위논문, 공식 데이터셋 논문. 코칭 블로그·유튜브·상업 홍보물은 제외
2. **모든 항목에 DOI 또는 공식 URL**을 적고, 그 링크를 실제로 열어 확인한 것만 넣는다. 열지 못했으면 넣지 않는다
3. 확인 수준을 표시: `본문 확인` / `초록만 확인`
4. 수치(각속도·시간·정확도 등)는 **연 본문/초록에 있는 값만**, 위치(쪽·표·그림 번호 또는 초록)를 함께 적는다. 기억으로 쓰지 않는다
5. 모르는 것은 "미확인"으로 남긴다. 그럴듯한 서지정보를 만들지 않는다
