   3bdf45d/A의 경계·점수·전체 summary가 기존 실행과 정확히 같아야 한다.
3. 진단 후 아래 제한된 후보를 동결하고, split 1–3 각각을 검증 fold로 남겨
   나머지 두 split의 PCE로 후보를 선택한다. 전체 개발 데이터에서 최종 후보를 선택한다.

## 진단으로 정한 수정 후보 (새 교차검증 전 고정)

- 자동 스캔은 3bdf45d 파라미터를 사용한다. 학습된 경계 정의의 변경으로 추론
  크롭과 MediaPipe 추적 초기 상태까지 바뀌지 않게 한다. scan의 원래 샘플링은 유지한다.
- 최종 분석 plateau: `.025, .05`; impact 창: `.75, 1.25`초.
- 음의 Address offset으로 남는 유효 각도 관측량이 `0, .1, .2, .3`초보다 작으면
  offset 전 onset을 사용한다. 관측량은 기존 visibility/이전값 유지 행 수 × 샘플 간격이다.
  각도 값·점수·개별 영상 ID를 조건에 사용하지 않는다. 누락된 관측량은 기존 동작을 따른다.
  첫 시도는 회복 불가능한 장기 비가시 구간도 onset을 복원해 fold 평균 −2.01%p로 탈락했다.
  두 번째 시도는 offset 전 onset으로 실제 최소 관측량을 회복할 수 있을 때만 가드를 적용한다.
  같은 후보 범위를 유지하며 실패한 실행 로그도 보존한다. split 4는 두 시도 모두 열지 않는다.
- 나머지는 A값 그대로다. 후보 16개, 앱 7개 Top/Impact 참조 거리 비악화·거부 0 및
  점수 ≥3bdf45d를 만족한 후보만 GolfDB에서 비교한다. 점수 상승을 정확도 향상으로 해석하지 않는다.
- 목적함수/허용오차/거부 분모는 기존 common.py 그대로다. 동점은 작은 관측량 가드 우선.
  최종 3-fold 산술 평균이 원 A의 fold별 선택값보다 1%p 넘게 낮으면 완료 판정하지 않는다.
  고정 A 파라미터를 각 split에 적용한 비교도 별도로 보고한다.
