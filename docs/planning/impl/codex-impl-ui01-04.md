## 3. 화면별 구현
- **공통(상단 메뉴):** 시안처럼 로고 `Swing.Lab`, 텍스트 메뉴(실시간 캠·내 기록·테마·KO/EN), 로그인 버튼. 기존 기능·링크 그대로
- **UI-01:** 좌 텍스트·버튼, 우 이미지, 하단 "내 스윙 기록" 띠. 설명문은 시안 문구("내 영상으로 스윙의 흐름을 확인하고, 다음 연습에서 바꿀 점을 찾아보세요.")를 KO 신규 문구로, EN 번역 추가. 촬영 안내 한 줄 추가. 기존 SPINE/SHOULDER 계측 패널은 시안에 없으므로 제거
- **UI-02:** 제목 "분석 구간 선택" + 파일명 + "파일 변경" 버튼(파일 다시 선택), 감지 상태 큰 코발트 카드(감지 중/완료/실패 문구 — 실패 문구 기존 `trim_detect_failed` 재사용) + 큰 구간 길이 숫자, 주 버튼 "이 구간으로 분석 시작", 개인정보 안내. **하단 통합 타임라인:** 브라우저에서 `<video>`+`<canvas>`로 장면 썸네일 줄(8~12장)을 만들고, 그 위에 선택 구간 강조와 양 끝 핸들(키보드 조작 가능, 이름 있는 `input[type=range]` 2개를 겹치거나 동등 접근성), 시작·끝·길이 표시, 현재 재생 위치. **손목 파형은 이번에 넣지 않는다**(서버 응답에 데이터 없음 — 서버 변경 금지). 기존 최소 1초 제약은 유지하되 버튼 옆에 사유 표시
- **UI-03:** 큰 "분석 중…" 제목 + 파일명, 코발트 진행 카드(진행률 큰 숫자·이름 있는 진행 막대), 단계 목록(업로드 완료→스윙 구간 자르기→관절 포즈 추적·7단계 구분→점수 계산→완료; 기존 job stage 값에 매핑), "뒤로 가기" 버튼 + 안내문 3줄. 뒤로 가기 시 **폴링 중지 + 늦게 도착한 응답 무시**(프론트에서 현재 작업 ID 비교) — ISSUE-02
- **UI-04:** 제목 "7단계 스윙 분석" + 파일명 + 상태 칩, 코발트 총점 카드, 지표 카드 4개(이름 아래 한 줄 설명 + 도움말 아이콘 `title`/툴팁), 진단 목록(KO 등급 라벨), 7단계 대표 장면 줄. 스크롤 아래(파형·다시보기·비교·코칭·공유/저장)는 **배치 유지, 색·여백만 새 토큰**. 카드 ✕ vs 진단 warning 불일치는 **고치지 말고** 보고서에 남김(G2)
