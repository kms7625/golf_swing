## 6. 공통 기기·키보드·검증 경계

구조 제안: 의미 있는 페이지 제목과 주 작업 영역을 두고 전환 시 제목 또는 오류 요약으로 초점을 옮긴다. 버튼·입력의 순서와 시각적 읽기 순서를 맞추며, 현재 초점 표시와 움직임 감소 대응을 유지한다. 색·차트만으로 판정/미검출을 전달하지 않는다. UI-07이 열려 있는 동안 배경 조작을 제한하고 닫으면 호출 위치로 초점을 돌린다.
