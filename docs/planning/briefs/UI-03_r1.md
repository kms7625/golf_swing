# UI-03 분석 진행 — 첫 시안 생성 브리프

작성일: 2026-10-08 · project_id: `swinglab-web-ux-20261008` · scope_id: `D04-10_D05-07_UI-03` · state_revision: **6** · UI revision: **1** · 구조 revision: **2** · **DRAFT**

D05 §4 순서. 대표 상태는 **서버 접수 후 관절 포즈 추적·7단계 구분 중**, 비회원·KO·어두운 테마 한 장이다. APR-05는 구조 동의와 생성 요청만 기록한다. 결과 이미지·구현 승인이 아니다. `ROLE_GUIDED`, 독립 하위 에이전트 실행 없음.

## 1. 화면 목적 / 첫 행동 / 지원 기기와 화면 비율

- 목적: 처리 대상, 현재 단계, 진행률과 화면을 떠날 때의 결과를 이해하게 한다. 관련 REQ-02·08·09, ISSUE-02·11, Nielsen NE-02·04·12.
- 첫 행동: **현재 진행 상태를 확인하고 기다린다.** 새로 분석을 실행하는 주 버튼은 필요하지 않다. 보조 행동은 이름 있는 **뒤로 가기** 버튼이며, UI-02의 파일 선택 화면으로 이동하는 제안이다.
- 데스크톱 웹 **16:9, 생성 목표 1536×864px**, 한 장. 좌표·크기·색상 수치는 미승인 제안값이며 출력 치수는 생성 후 기록한다. 임의 크롭·리사이즈하지 않는다.
- 대표 데이터: 예시 파일 `일반.mp4`, `stage=analyzing`, `progress=30`. `server/main.py`의 `jobs.set_stage(job_id, "analyzing", 30)`와 단계 순서를 근거로 한 합성 상태다. 실제 실행·영상 분석 측정값이 아니다. 30%는 처리 시간·프레임의 30%를 뜻하지 않는다.
- 전송 중·오류·완료·취소 확인 모달·모바일 시안은 이번 생성에서 제외한다.

## 4. 컴포넌트 형태·정보 밀도·색/글자 역할

- 승인 UI-01·02의 거의 검은 녹색 배경, 한 단계 밝은 카드, 얇은 올리브 경계선, 둥근 모서리를 이어간다. 색상은 승인 파일을 눈으로 참고하며 정확한 RGB를 역측정·확정했다고 주장하지 않는다.
- 라임: 브랜드 LAB·선택 언어·진행 막대·현재 단계·보조 버튼 테두리. 민트: 완료 체크·진행 수치·키보드 초점. 밝은 본문과 회녹색 보조 문구의 위계를 유지한다.
- 한글은 승인 시안과 같은 단정한 산세리프 느낌, 제목은 굵게, 값은 고정폭 숫자 느낌. 외부 폰트 파일은 추가하지 않는다.
- 핵심 정보는 제목 → 파일 → 진행률 → 단계 → 이탈 결과 순서. 생성 이미지의 장식·효과가 진행 상태를 가리지 않게 한다.
- ISSUE-11 구현 제안: 보이는 `분석 진행률`을 progressbar의 접근 가능한 이름에 연결하고 기존 0–100 값 의미를 보존한다. 현재 단계와 값을 묶어 읽으며 단계가 변할 때 정중한 상태 알림을 제공한다. 반복 조회마다 같은 알림을 쏟지 않는다. 화면 진입/완료 때 제목 초점, 키보드 버튼 동작, 대비·움직임 감소는 후속 실제 검증 대상이다. 이미지 한 장으로 ARIA·키보드 검증을 통과 처리하지 않는다.

## 6. 이번 이미지에 넣지 않을 기능·자산

- 실제 서버 취소, 일시정지/재개, 백그라운드 작업함, 자동 결과 저장, 남은 시간, 프레임 실시간 계수, 영상 미리보기, 점수 결과, 결제·새 로그인 게이트는 넣지 않는다.
- `AnalyzeProgress.tsx`의 현행 입력은 stage/progress뿐이다. 파일명·뒤로 버튼·이탈 무효화·이름 연결/알림은 이번 구조 개선 제안이며 코드 변경은 하지 않는다.
- ISSUE-02 제안 계약: 뒤로 가기 → UI-02 파일 선택; 조회 중지와 활성 요청 무효화 → 이탈 전 업로드 접수/조회 성공·실패 응답이 이후 화면·결과·오류를 덮지 않음. 상단 홈·캠·기록 이동에도 같은 무효화 정책이 필요하다. 서버 처리는 별개로 계속된다. 서버 취소 API 추가를 범위에 넣지 않는다.
- 현재 `App.tsx`는 상단 캠·기록 이동 시 조회를 계속하며 홈 이동도 이미 진행 중인 응답을 무효화하지 않는다. 새 안내는 **현재 동작 설명이 아닌 개선안**이다. 새로고침·탭 닫기 뒤 작업 복원은 미확인, 이번 문서에서 보장을 만들지 않는다.
- Nielsen NE-02: 이번은 접수 후 30% 상태만 표현한다. 접수 전에는 완료로 표시하지 않는 별도 전송 상태가 필요하나 이번 이미지를 추가로 만들지 않는다. NE-03 오류·초안 보존 역시 후속 상태 명세 대상이며 해결 완료로 표시하지 않는다.
