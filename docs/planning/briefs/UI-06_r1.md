## 대표 상태·배치

KO / 로그인 완료 / 기록 4개 / 점수 추이 / 마지막 행의 삭제 확인을 펼친 **단일 화면**. 데스크톱 16:9, 생성 목표 2048×1152. 목록을 왼쪽 약 58%, 추이를 오른쪽 약 38%로 두어 읽기 순서는 제목→최근 기록→변화→계정 관리다. 인물 사진·썸네일은 사용하지 않는다. 수치·날짜·파일명·계정은 합성 예시이고 상단에 `예시 데이터`를 표시한다.

상단은 Swing.Lab / 실시간 캠 / 내 기록(활성) / 테마 / KO·EN / 로그아웃. 제목 `내 스윙 기록`, 보조 `연습 계정 · 예시 데이터`, 주 행동 `새 영상 분석`(UI-02 직접 이동 제안). 계정 삭제는 페이지 하단 별도 영역에 `계정 관리`, `회원 탈퇴 (모든 기록 삭제)`로 분리한다.

| 날짜 | 파일명 | 점수 | X-FACTOR | 척추각 변화 |
|---|---|---:|---:|---:|
| 10/08 18:30 | 스윙_1008.mp4 | 81 | 42.0° | 6.2° |
| 10/05 18:20 | 스윙_1005.mp4 | 77 | 44.0° | 7.0° |
| 10/02 18:10 | 스윙_1002.mp4 | 79 | 40.0° | 6.8° |
| 09/28 18:00 | 스윙_0928.mp4 | 73 | 38.0° | 8.2° |

각 행에 독립된 `보기`·`삭제` 버튼. 날짜·파일명·점수는 항상 노출하고 지표는 상세 및 추이 영역으로 보낸다. 그래프는 시간순 09/28→10/02→10/05→10/08, 점수 73→79→77→81을 동일하게 표시한다. 0–100점 축과 데이터 점을 사용하고 가짜 상승 일변도 그래프를 만들지 않는다. `처음보다 +8점`은 점수 차이다.

지표 영역 `지표별 추이 (처음 → 최근)`는 `척추각 변화 8.2° → 6.2° / 2.0° 감소`, `X-FACTOR 38.0° → 42.0° / 4.0° 증가`, `어깨 최대 회전 68.0° → 72.0° / 4.0° 증가`를 **모두 같은 남색**으로 표시한다. `증감은 변화량이며, 좋고 나쁨의 판정이 아닙니다.`를 붙인다(NE-21). 점수·판정 로직과 X-Factor P5는 변경하지 않는다. 기존 지표명 통일 문제도 이 시안에서 임의로 결정하지 않는다.

마지막 행 바로 아래에 옅은 파랑 인라인 확인 영역: `이 기록을 삭제할까요?`, 굵은 `스윙_0928.mp4`, `09/28 18:00 · 73점`, `저장된 분석 결과가 삭제되며 되돌릴 수 없습니다.`. `취소`와 독립된 `기록 삭제` 버튼. 기본 초점은 취소에 별도 외곽선으로 표현한다. 같은 버튼의 3초 내 재클릭이나 타이머 확인을 사용하지 않는다(NE-22). 삭제할 대상과 범위를 읽고 별도의 확인 동작을 수행하는 제안이다.
