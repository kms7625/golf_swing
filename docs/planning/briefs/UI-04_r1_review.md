## 4. 현행 기능과 제안의 경계

- 현행 `ResultScreen.tsx`는 파형이 장면보다 먼저이며 저장·공유가 상단에 있다. 이번 지시에 따라 대표 장면은 첫 화면, 파형·다시보기·비교·코칭·공유/저장은 스크롤 아래 순서로 브리프에 제안했다. 코드에 반영하지 않았다.
- 어깨 카드에 상태를 새로 판정하지 않았다. 척추·X-Factor·감지 수의 상태와 등급 경계는 현행 코드에서 확인했다. 기존 카드와 진단의 임계값 차이도 수정하지 않았다.
- 지표 설명·새 출처 문구·도움말·저장/공유 오류 상태·부분 데이터 안내는 UI 제안이며 신규 i18n 키나 기능을 구현하지 않았다.
- X-Factor P5는 사용자 미결정이다. 17.0° 카드의 ✕와 warning 진단, 총점의 기본 15점 감점을 유지한 합성 예시다.
- **NOT_RUN**: 실제 분석·서버 요청·브라우저·모바일·공유/저장·빌드·자동 코드 테스트·키보드·보조기술 검증. 정적 시안 작업에서 앱 동작을 검증했다고 주장하지 않는다.
