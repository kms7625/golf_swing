## 접근성 우려·미검증

- 두 안 모두 초점선이 눈에 보이지만 PNG는 실제 버튼이 아니다. 구현 시 실제 버튼 요소, 키보드 활성화, 초점 순서·가림 여부, 접근 가능한 이름을 확인해야 한다. 이번 작업은 코드 수정 금지이므로 시각 표현까지 제공한다.
- A의 사진 위 ‘이미지 예시’ 흰 글자는 배경에 따라 대비가 달라질 수 있다. 단색 배지 배경을 추가하는 수정 후보가 있다. 사진 속 작은 무늬·숫자는 본문 정보로 쓰지 않는다.
- B의 작은 메뉴·촬영 안내·이미지 예시·하단 설명은 이미지 축소 시 읽기 부담이 생길 수 있다. 명조 제목의 크기·행간과 본문 대비는 실제 화면에서 확인해야 한다.
- 두 안의 실제 대비율, 글꼴 렌더링, 터치 영역, 화면 낭독기, 확대·모바일·EN 전환은 검증하지 않았다. ‘접근성 통과’로 기록하지 않는다.
- 샘플 로딩·중복 실행 방지·이탈 후 응답 무효화(NE-01·04), 기록의 빈 상태와 오류 분리(NE-09), 뒤로·새로고침의 복원(NE-07)은 이 대표 정적 화면에 나타나지 않는다. 해당 문제의 해결 여부는 미확인이다.
- NE-15는 설명문을 결과 중심으로 바꾸었지만 기존 제목 ‘계측 장비처럼 읽는다’는 남겨 두었다. 전체 문구 이해도 개선이 검증된 것은 아니다.
