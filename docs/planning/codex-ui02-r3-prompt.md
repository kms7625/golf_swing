## 1. 수정 내용
1. **통합 타임라인:** 시작/끝 슬라이더 두 개를 없애고, 영상 아래 **하나의 범위 타임라인**으로 합친다 — 필름스트립(장면 썸네일 줄) 위에 감지 구간을 강조하고 양 끝 핸들로 조절, 현재 재생 위치 표시. 시작·끝·길이 값과 라벨은 핸들 근처/타임라인 아래에 유지(접근성: 각 핸들에 이름)
2. **감지 근거 시각화:** 타임라인과 같은 시간축에 **손목 높이 변화 파형**을 겹치거나 바로 위에 두고, 자동 감지 구간을 음영으로 표시. 짧은 설명 "손목 움직임이 큰 구간을 스윙으로 찾았어요"(신규 문구 후보). **실제 앱이 쓰는 신호인지 0절 코드로 확인하고, 다르면 실제 신호 이름으로 표기**
3. **시각 강화:** r2a 톤 안에서 더 과감하게 — 굵은 숫자(구간 길이), 코발트 강조 면, 여백 정리. 상단 구조와 메뉴는 r2a와 동일
4. 감지 실패 상태는 이번 이미지에 넣지 않되, 브리프에 실패 시 파형·음영 처리 방식을 한 줄로 적는다
